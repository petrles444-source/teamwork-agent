# {{ПРОЕКТ}} — статус проекта и дорожная карта

Документ отражает состояние **продукта**, а не распределение работы между
агентами. Здесь нет имён и зон: есть что сделано, что не сделано, что
измерено и что делать дальше.

**Читай этот документ, если хочешь понять не «что делает программа», а «почему
она пока не готова».** README отвечает на первый вопрос, этот — на второй.

Дата среза: `{{ДАТА}}`. Все числа — реальные прогоны, а не цели.

## Как пользоваться шаблоном

| Раздел | Что делать |
|---|---|
| 1–2, 8 | Переписать под свой проект. Формат тот же. |
| 3 | Разбить по фазам/этапам. Статус `✅ / ⚠️ / ❌` и колонка «готово, когда». |
| 4 | **Самый важный.** Если есть цифры качества — писать только честные. |
| 5 | Описать физически недостижимое, чтобы не пытались снова. |
| 6 | Дорожная карта: пронумерованные задачи с точкой входа. |
| 7 | Приёмочные метрики: цель против факта. |
| 9 | Команды самопроверки. Должны работать. |

Правила, которые нельзя нарушать при заполнении:

1. **Число пишется только вместе с командой, которая его дала.** «Работает»
   без команды не является результатом.
2. **Цель и факт — разные колонки.** Совпадение подделывается тривиально:
   достаточно поставить в «факт» то же, что в «цель».
3. **Отменённые числа помечай явно.** Переписать раздел целиком лучше, чем
   оставить ошибочные цифры «для истории» без пометки: агент их процитирует.
4. **Неизвестное — «не измерено», а не прочерк.** Прочерк читается как «минус
   бесконечность».

## 4. Качество и измерения — честная таблица

Если в проекте есть метрики качества, этот раздел переписывается чаще всего и
чаще всего содержит ошибки. Проверь себя:

- **На каких данных мерил?** Если данные переразмечали — старые числа недействительны.
- **Какая доля положительного класса?** Метрика вроде «precision@1000 ≥ 0.40»
  при базе 0.2% может быть арифметически недостижима, и это проверяется
  делением, а не обучением.
- **Какое распределение метрики?** Один прогон с seed 42 — не измерение,
  а число. Приводи диапазон по нескольким сидам.
- **Как определена сама метрика?** «Топ-1000 из всей выборки» и «топ-1000 из
  каждого фолда» — разные вопросы с разными числами.

## 5. Почему что-то недостижимо

Опиши цели, которые физически не бьются, **до** того, как их потратит время
кто-то ещё. Формат: цена операции на единицу · бюджет · сколько единиц он
покупает · почему это не чинится оптимизацией · что нужно решить
(продуктовое или техническое).

так и напиши. Выдуманная причина хуже признания.
